# Chemistry Review Cores

## Review topic

**Observation -> Evidence -> Chemical Inference**

This folder is a review package for comparing the six Chemistry layers on one governed topic:

`Core1 -> Core1A -> Core1B -> Core2 -> Core2A -> Core2B`

These PDFs are **review samples**, not replacements for canonical generated artifacts.

## Grounding

Core1, Core1A, Core2 and Core2A are grounded in the current Chemistry authority on `v2-chemistry-core1a-core2a-foundation` / PR #362, especially:

- `CAP-SEPARATE-OBSERVATION-INFERENCE`
- problem family `PF-EVIDENCE_TO_CLAIM`
- the Redox production profile
- NCERT Exemplar source items `U2Q15C` and `U2Q35`

Core1B and Core2B are **proposed static learner-product designs under review**. They do not change Core1A or Core2A.

## Layer boundary

- **Core1** - semantic teaching authority: capability, representation, reasoning rule, verification and problem-family truth.
- **Core1A** - governed learner teaching realization. Unchanged by this review.
- **Core1B** - static open-ended consolidation. Learner attempts first; self-guided help appears at the bottom of the page as cue -> working frame -> detailed answer/check.
- **Core2** - source-transfer authority: governed source asks, source identity, problem-family demand and answer/marking authority.
- **Core2A** - legal purpose-conditioned learner practice with provenance, clues and answer closure. Unchanged by this review.
- **Core2B** - static reduced-cue transfer sequencing over already-legal Core2A items. It does not invent a new Chemistry question or adapt live to learner responses.

## Review invariant

`A-layers govern what is valid. B-layers compile how the learner experiences already-valid material.`

Core1B's cognitive job is **schema reconstruction and independent consolidation**. Core2B's cognitive job is **schema selection and transfer under changed/reduced cues**. The difference is not simply easy versus hard.

## Non-claims

This package validates architecture and learner-product boundaries. It does **not** claim that a learner mastered, retained or robustly transferred the Chemistry merely because the PDFs exist. Those claims require external learner evidence.
