# Grade 9 Chemistry

## Subject-wide topic delivery standard

Every Chemistry topic that is taken up for learner-facing production must create exactly **two PDFs**:

1. **Core Study Guide** — teaching narrative plus:
   - Appendix A — Core Practice
   - Appendix B — Core Solutions
   - Appendix C — Printable Handout
2. **ExamSIDE Solution & Transfer Book** — attempt-first external questions with source/difficulty/transfer/concept badges, visible PRIMARY-vs-SUPPORT concept segregation, progressive H1-H3 hints as required, Core/source links and complete solutions.

Appendix C is mandatory and lives inside the Core Study Guide; it is not a third learner-facing file.
