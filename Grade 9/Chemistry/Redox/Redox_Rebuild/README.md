# Redox Reactions — Chemistry review package

This folder packages the completed Grade 9 Redox pilot for independent chemistry, teaching, assessment, source-grounding and publication review.

## Start with the learner experience

The two reviewed learner PDFs are **prepared but not committed in this automated draft**. Their exact hashes/page counts are in `Prepared_Artifact_Fingerprints.json`; committing those binary snapshots is a blocking task before the PR is marked ready.

| Prepared artifact | Review focus |
|---|---|
| `Redox_Core_Study_Guide.pdf` (68 pages) | Explanation order, concept helpers, chemistry notation, misconceptions, guided/faded practice and the final P1–P7 pipeline. |
| `Redox_ExamSIDE_Transfer_Book.pdf` (85 pages) | ST01–05 canonical PYQs, ST06 cumulative challenge (pp61–73) and full 74-candidate corpus audit (pp74–85). |
| `Redox_ExamSIDE_Ledger.json` | Machine-readable frozen candidate ledger. |
| `Source/Source_Fingerprint.json` | SHA-256/page-count fingerprint of the supplied Redox source authority. The original source PDF is not committed in this draft. |

For PDF feedback, record filename, PDF page, subtopic/concept/question ID, learner consequence and proposed repair. Add a screenshot when layout or notation is involved.
