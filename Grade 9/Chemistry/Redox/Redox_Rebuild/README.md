# Redox Reactions — Chemistry review package

This folder packages the Grade 9 Redox pilot used to validate the **subject-wide Chemistry publication schema**.

## Important migration note

The existing Redox learner PDFs were produced before the final Chemistry topic-delivery contract was frozen. They therefore remain useful review snapshots for Redox content/corpus evidence, but they are **not yet conforming final Chemistry topic products** because the Core files were not generated with the mandatory Appendix A/B/C structure, including **Appendix C — Printable Handout**.

The subject-wide standard now requires every Chemistry topic to produce exactly:

```text
1. Core Study Guide
   Appendix A — Core Practice
   Appendix B — Core Solutions
   Appendix C — Printable Handout

2. ExamSIDE Solution & Transfer Book
   concept segregation + badges + H0/H1-H3 + transfer + Core/source links + complete solutions
```

Do not mark this Redox pilot publication-ready until the topic artifacts are regenerated/migrated to that contract.
