# Grade 9 Learning Enrichment

Use the sequence `Question -> concepts/prerequisites -> What should I notice? -> helper -> progressive hints -> strategy -> worked solution -> misconception clinic -> diagnostic/repair -> transfer -> takeaway`.

`What should I notice?` highlights salient structure without solving the item. A helper answers `What should I think about first?` without giving away the setup.

Use 4–5 hint stages when useful, fewer when not: H1 direction; H2 concept/model; H3 representation/connection; H4 setup/equation; H5 final push without final answer. The existing 10/25/45/70/90 reveal values are descriptive heuristics only.

Misconceptions must describe a specific wrong model. Use `wrong response -> plausible misconception -> diagnostic probe -> targeted repair -> retry -> transfer check`. Do not infer a persistent misconception from one arithmetic slip or ambiguous error.

Separate strategy, complete worked solution, useful alternative methods, and subject-appropriate validation checks.

Unaided/lightly hinted success is stronger evidence of independent recognition than late-hint-assisted success, but help use must not be framed negatively.
