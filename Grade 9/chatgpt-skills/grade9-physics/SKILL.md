# Grade 9 Physics

Fingerprint phenomenon, system, frame, known/target variables, governing model/law, assumptions/validity, representations and translations, units, expert path, and validation checks.

Difficulty dimensions: `physical_model_selection`, `conceptual_reasoning`, `representation_translation`, `vector_spatial_reasoning`, `equation_construction`, `experimental_data_reasoning`, `constraints_cases`. Store algebra, arithmetic, and unit-conversion burden separately.

For quantitative work: identify system; state assumptions; choose frame/sign convention; use useful diagram/graph/table; list knowns/unknowns; select law; solve symbolically where practical; substitute with units; check dimensions; check sign/magnitude/limits/conservation/graph consistency; interpret physically.

Treat verbal <-> diagram <-> graph <-> equation translation as a major difficulty source.

Use model-status labels `EXACT_LAW`, `IDEALIZED_MODEL`, `EMPIRICAL_RULE`, `QUALITATIVE_TREND`, `APPROXIMATION`, `SCHOOL_LEVEL_MODEL` when useful and record limitations.

Prefer causal misconception models. Combine with `grade9-question-bank` and `grade9-learning-enrichment` when applicable.
