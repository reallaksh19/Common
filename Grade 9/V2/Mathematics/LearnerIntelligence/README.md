# MATH-V2-02 — Mathematics Learner Intelligence acceptance proof

This folder is a **subject acceptance proof** for the shared V2 Learner Intelligence semantics. It does not own canonical Mathematics truth and it does not make Study Synthesis or teaching decisions.

## Boundary

```text
PUBLIC_SYNTHETIC Math work evidence
+ synthetic canonical interface refs
→ deterministic checkpoint observations
→ cautious diagnostic cases
→ qualitative capability state
→ descriptive ResearchLearnerView
```

The canonical interface fixture contains identifiers only. It is a temporary conformance surface while MATH-V2-01 is under review; it is not a second canonical registry.

## Central invariant

```text
correct modelling + invalid downstream algebra != modelling failure
```

A wrong final answer cannot erase successful upstream checkpoints.

## State interpretation

- `READY`: positive independent evidence with no contradicting failure in this fixture.
- `DEVELOPING`: localized evidence is mixed, prompted/guided, or contains an ordinary failure that is not sufficient for confirmed repair.
- `UNKNOWN`: evidence is absent or materially ambiguous.
- `REPAIR_REQUIRED`: deliberately not reachable from one ordinary failure in this acceptance proof.

`ROBUST` is also not awarded by this small fixture because durable transfer/retention evidence is absent.

## Verification split

The view records separately:

```text
can_verify_when_prompted
self_initiated_verification
```

Prompted verification success is evidence that the check can be performed under prompting. It is not evidence that the learner independently deploys verification during solving.

## Non-goals

No real learner data, no psychometric mastery probability, no StudyModel treatment, no LearningDesign choreography, no scheduler, no learner PDF, no benchmark comparison.
