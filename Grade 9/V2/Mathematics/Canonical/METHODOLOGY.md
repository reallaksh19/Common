# Mathematics canonical reasoning methodology

## 1. Reasoning checkpoints

A Mathematics problem family is represented as explicit semantic checkpoints:

1. understand the mathematical object;
2. select or interpret a representation;
3. recognize structure;
4. select an operation, theorem, or relation;
5. transform;
6. preserve the relevant invariant/equivalence;
7. check conditions/domain;
8. verify the result.

A wrong final answer does not imply that every earlier checkpoint failed.

## 2. Foundational capability decomposition

The initial registry separates:

- word modelling;
- geometric modelling;
- linear-system setup;
- equality preservation;
- expression identity;
- variable semantics;
- sign propagation;
- representation translation;
- ordered-pair semantics;
- binomial-square expansion;
- solution verification.

This deliberately prevents `algebra error` from becoming a blanket topic label.

## 3. Diagnostic probes

Canonical probes are narrow discriminators. A suspected equality-preservation failure receives a low-load equality probe, not a longer word problem. Ambiguous coordinate semantics receives an ordered-pair/slope probe.

## 4. Verification

Verification is a first-class mathematical capability. The canonical methods include:

- substitution into original relations;
- equivalence checking;
- domain/constraint checking;
- alternate representation.

The learner behavior `SELF_INITIATED_VERIFICATION` belongs downstream in learner evidence/state.

## 5. Canonical package identity

The deterministic package binds the exact semantic source files and their SHA256 digests. The package digest is computed from the package payload excluding its own `package_digest` field.
