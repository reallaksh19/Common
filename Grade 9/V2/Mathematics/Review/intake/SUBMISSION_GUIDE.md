# Submission guide

A real reviewer submission must use `source = HUMAN_SUBMISSION`, `test_only = false`, the exact Mathematics candidate SHA, the exact real authorization-registry version, and the rubric ID for the review dimension.

PASS requires every required rubric criterion to be present and PASS, with no open blocking finding. A FAIL may include one or more failed criteria/findings. The intake engine rejects unknown reviewers, cross-class use, SHA mismatch, incomplete rubrics, AI/CI substitution, and inconsistent PASS claims.

The real registry is intentionally empty. Reviewer authorization must be an explicit repository change; this file does not authorize anyone.
