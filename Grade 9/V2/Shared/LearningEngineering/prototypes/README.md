# Shared SKP semantic prototypes

Status: **PROTOTYPE ONLY — NON-RUNTIME**

This directory contains experimental contracts for roadmap modules that remain `PLANNED`.
Prototype files deliberately do not use the roadmap `target_contract` paths and therefore
cannot be mistaken for promoted shared-module contracts.

Current prototype tranche:

- concept;
- relation + applicability conditions;
- reasoning sequence;
- representation + translation semantics;
- verification route;
- problem family.

The synthetic fixture proves subject-neutral structure. The bounded Physics pilot at
`../pilots/physics-relative-g-cancellation.standard.prototype.json` projects exact
repository-owned semantics for `PHY-PF-RELATIVE-G-CANCELLATION` and remains `HELD`.

Cross-subject fit tests also project existing repository authority without changing it:

- Mathematics `MATH-PF-EUCLID-CLASSIFICATION` demonstrates that a legitimate problem family need not own a formal relation and that mathematical transition semantics must survive projection;
- Chemistry `PF-RULE_WITH_EXCEPTION` demonstrates that a legitimate family can have no required representation and can expose a governed role sequence without authorized semantic-job prose.

Those cases are why the prototype permits empty concept/relation/representation axes where the source does not own them, preserves richer variation/transfer structures, and allows unresolved semantic-job detail instead of filler.

The Physics pilot intentionally does not invent:

- official curriculum authority;
- pedagogical primary/secondary representation decisions;
- representation-translation evidence;
- learner-fragility classifications.

Passing prototype tests is evidence that the shared shape can represent current subject semantics and their unresolved gaps. It is not Engineering readiness, SKP promotion, publication authority, or permission for bulk library population.
