# Physics Core1B v9 — CCU-governed Concept reconstruction

Core1B is generative-dominant reconstruction of already authorized Core1A technical structure. V9 requires CCU custody before learner reconstruction so no agent can skip a fragile asset or silently reuse the Core1A worked state.

## Authority path

`released Core1A authority → CCU lineage/coverage → CDAU purpose/differentiation → SDU → Concept TTU → Core1B runtime`

## Required CCU guarantees

Core1B may use only canonical assets with explicit CCU dispositions. `TRANSFORMED` assets must carry parent asset IDs and transformation refs. Silent omission is illegal.

Every learner-facing task must have:

- stable question/task ID;
- visible source class and source label;
- bucket/concept metadata;
- canonical completed response/diagram/derivation/rubric;
- answer reveal rule;
- example fingerprint when numerical/problem-like;
- cross-Core relationship classification against adjacent Core1A material.

Exact Core1A numerical examples or complete diagrams are prohibited by default unless the relationship is an explicit `FADING_ANCHOR`; a fading anchor is a learning transition, not independence evidence.

## Reconstruction modes

Hard Core1B must use high-value transformations appropriate to each fragile checkpoint:

`PREDICTION | COMPLETION | GENERATION | SELECTION | DISCRIMINATION | DIAGNOSIS | DERIVATION_CONNECTION | VERIFICATION`

A pile of cosmetic blanks is insufficient. A fragile checkpoint may not be represented only by passive reference prose.

## Difficulty

Core1B shares the SDU v2 intrinsic Easy/Medium/Hard badge with Core1A, but actual length is independently derived. Student knowledge percentage does not control authored Core1B depth.

## Evidence

Canonical reveal/full solution remains teaching evidence, not mastery. Independence requires observed low-hint/retrieval performance under the existing Core1B runtime evidence contract.

## Release

Core1B requires `G_CUSTODY_COVERAGE`, `G_PURPOSE`, `G_DIFFERENTIATION`, `G_DIFFICULTY`, `G_TTU`, released Core1A authority and runtime evidence integrity.
