# Physics Core1B v7 — semantic reconstruction from TTU v2

Core1B asks whether the learner can reconstruct and independently use fragile technical structure already authorized upstream.

## Core rule

A Core1B technical task is not complete because it shows a diagram with blanks. It must be the **reconstruction realization of an existing TTU v2**.

The learner-facing state must therefore contain:

1. deliberately omitted Physics elements identified by canonical TTU element IDs;
2. an explicit learner reconstruction task;
3. fixed preauthored help tied to those omitted IDs;
4. a canonical completed state revealed only after attempt;
5. at least one verification rule the learner can apply before reveal.

## Meaningful omissions

Valid omissions include frame labels, vectors/directions, components, forces, event markers, graph features, equation terms, boundary/model conditions and intermediate states.

Invalid omissions include cosmetic blanks, arbitrary hidden numbers, copy-the-answer tasks, or labels that do not affect reasoning.

For a Hard substantive Core1B task, the default expectation is at least two meaningful omissions, including a representation/model element where material.

## Help

Help is fixed, not improvised downstream. For substantive tasks the default sequence is:

`H1 NOTICE → H2 REPRESENT → H3 START`

Every help step names the omitted element(s) it supports. Dynamic new Physics semantics may not be introduced before the canonical reveal.

## Verification

"Compare with the answer" is not verification. Use an inverse relation, substitution-back, limiting case, sign/direction, dimensions, boundary condition, graph behaviour, alternate representation or model-validity rule.

Full solution exposure remains teaching, not mastery evidence.
