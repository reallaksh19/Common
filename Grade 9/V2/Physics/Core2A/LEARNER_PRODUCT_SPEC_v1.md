# Physics Core2A v1 — Declarative Worked Transfer Atlas

## Learner-product purpose

Core2A is a **self-guided declarative problem-learning product**. It asks:

> Show me how an expert recognizes, represents and solves this problem family.

Core2A is not merely an answer key. It should help a learner conceptualize the question structure at solution level.

## Frozen-source rule

Core2 source items are already frozen authority.

Core2A must **not rewrite a frozen Core2 question to make it easier**. Difficulty adjustment happens through:

- support density;
- ordering;
- prerequisite explanation;
- completion level;
- visual support;
- clearly labelled `GENERATED_ORIGINAL` variants.

Source identity and source wording remain under Core2 custody except through governed source-integrity correction.

## Canonical worked-problem grammar

For each nontrivial item, provide:

```text
QUESTION
-> difficulty + required knowledge
-> WHAT SHOULD I NOTICE?
-> problem representation
-> WHY THIS MODEL?
-> FIRST MOVE
-> full working
-> physical / dimensional / limiting check
-> common wrong route
-> WHY THIS QUESTION IS HARD
-> WHAT WOULD CHANGE IN A VARIATION?
```

An alternate solution is optional and should be included only when it teaches a genuinely useful second representation or method.

## Difficulty pathways

Support may be adjusted without changing the governed question:

### LOW PRIOR
Foundation bridge -> full explanation -> worked first move -> full solution -> near-isomorphic generated practice.

### MID PRIOR
Checkpoint -> concise recognition cue -> partially completed solution -> learner finishes.

### HIGH PRIOR
Attempt first -> solution hidden initially -> compact expert solution and checks after attempt.

## Hint and answer quality

Core2A may expose more explanation than Core2B because its role is declarative problem learning. Still:

- hints must trace to taught Core1A capability;
- generated questions require exact provenance;
- full working must explain the reason for each major step, not only algebra;
- answer checks should include physical plausibility where applicable.

## Authority remains unchanged

Core2A remains the transfer-legality authority downstream of Core2 + Core1A taught-state receipts. A worked Core2A publication does not prove learner transfer or mastery.
