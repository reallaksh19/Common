# Physics Core2A v5 — worked problem TTUs with downstream reconstruction states

Core2A remains declarative-dominant worked problem-family learning. Student knowledge % or owner override changes support density and exemplar selection only.

Each representative legal exemplar is authored as a **TTU v2**.

## Core2A realization

Core2A normally exposes the canonical worked application:

`question → extract setup → construct representation → select relation → map givens → intermediate working → result → independent verification`

The underlying TTU must also define a semantically meaningful reconstruction state for downstream Core2B use, even if Core2A itself shows the completed expert state.

Core2B therefore does not invent arbitrary blanks or a different answer after the fact.

## Problem TTU requirements

- exact legal/source authority binding;
- canonical technical representation and stable element IDs;
- governing relation(s) and model conditions;
- visible intermediate expert working;
- canonical result;
- independent verification rule;
- preauthored omission plan suitable for a learner reconstruction/transfer realization where legal;
- fixed bounded help tied to omitted elements.

A large figure plus a final answer is not a TTU. A solved item with no independent check is not a complete self-help problem TTU.
