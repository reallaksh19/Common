# NLM build contract

## Core 1 teaching invariant

A reasoning move is not allowed to appear for the first time in Core 2. NLM Core 1 must explicitly teach:

1. choose the body or system;
2. identify interactions or momentum state;
3. build the exact representation (FBD, interaction pair, signed momentum state, v-t graph, or system boundary);
4. select the valid law only after the representation;
5. execute with signs, force ownership, units and system membership explicit;
6. interpret and independently check the result.

The 11 current competency families are motion vs force, body selection, net-force vector sum, Newton-II scaling, stopping-force chains, signed momentum, impulse, Newton-III pairs, system-boundary momentum conservation, recoil/rocket exchange, and v-t slope to friction force.

## Core 2 hint contract

Every hint rung is a semantic pair:

`open-ended prompt -> directly related reveal`

H1 asks for the decisive physical state/event/body/system/direction. H2 asks for the representation. H3 asks for the first executable relation or logical constraint only. A reveal must not answer a different question, leak a later rung, or resolve the requested result.

## Representation falsifiers

Fail the build for any of the following:

- generic force diagram when the problem state supplies different force magnitudes/directions;
- accelerating-train visual used for a braking problem;
- horizontal force drawn on an ideal frictionless constant-velocity puck without source support;
- third-law forces drawn as if they cancel on one body;
- momentum conservation shown without an explicit system boundary / external-impulse check;
- smooth-floor rolling torque invented for the ambiguous source Q10;
- solution figure content extending outside its semantic pane.

## Solution completeness

Worked pages use UNDERSTAND -> REPRESENT -> CONNECT -> CALCULATE -> INTERPRET. No force-ownership, sign, substitution, unit conversion, state-transition or conservation-validity step required by the learner may be silently omitted.

Each question must end with an explicit answer artifact, a problem-specific quick check, an independent alternate check where available, a watch-out, and an exact Core 1 review link.

## QA gates

- 20/20 direct Unit 9 demand families represented;
- zero unresolved answers;
- zero prompt/reveal hint validation failures;
- zero out-of-bounds text blocks;
- zero severe overlap flags;
- final PDFs re-rendered after the last change and visually sampled across concept, attempt and solution surfaces.
