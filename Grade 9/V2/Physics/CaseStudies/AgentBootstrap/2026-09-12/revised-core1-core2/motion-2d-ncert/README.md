# Motion in 2D - NCERT Class IX Exemplar selected subset

This topic pair is deliberately narrower than a full Motion in a Plane chapter. It is built only from the Motion-in-2D-related demands selected from the NCERT Class IX Science Exemplar set supplied by the user.

## Scope boundary

This source pool supports curved-path displacement, direction-changing velocity, qualitative circular acceleration, tangent release, gravity as the centripetal force, horizontal-launch versus drop timing, orbital tangent/inertia reasoning, and one accelerating-frame train/coin transfer.

It does not support a claim of complete coverage of oblique projectile equations, range/maximum-height formulae, boat/rain relative velocity, angular kinematics, or non-uniform circular motion.
