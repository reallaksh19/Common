# Vectors - Revised Core 1 and Core 2

This is the first topic-by-topic rebuild under the frozen learner-product format.

## Revised Core 1 intent

Core 1 builds the learner's reasoning machinery before transfer:

`recognise -> represent -> build/select relation -> execute -> interpret -> check`

Important competencies are taught through physical meaning, concept-native diagrams, relation construction and validity, a worked example, guided/faded practice, anti-triggers, and explicit answers.

The learner path contains 11 competency families:

1. scalar/vector distinction and signed axes
2. vector drawing, equality and opposite vectors
3. components, quadrants and angle reference
4. vector addition and resultant
5. subtraction and change vectors
6. magnitude/direction reconstruction
7. relative velocity
8. tangent/radial directions
9. interaction pairs and body ownership
10. angle between vectors and work
11. component bridge to Motion in 2D

## Revised Core 2 intent

Core 2 stress-tests the Core 1 machinery with 14 transfer questions.

Attempt pages use the frozen paired hint contract:

- H1 asks an open question about the decisive physics and then reveals only that concept clarification.
- H2 asks how to represent the state and then reveals the matching diagram/components/frame/relation.
- H3 asks what to write first and then reveals only the first executable equation/construction.
- Every prompt and reveal is self-contained and semantically paired.
- Exactly two writing lines are provided after H3.

Solution pages use the complete ladder:

`UNDERSTAND -> REPRESENT -> CONNECT -> CALCULATE -> INTERPRET`

No necessary algebraic, sign, state-transition, direction or unit-bearing step should be silently skipped. Each solution then gives an explicit Answer, Quick check, Check it another way, Watch out, and exact Core 1 review link.

## Layout/typography changes

- larger learner body text and equation text
- reduced decorative/fixed-height voids
- content-height practice cards and solution ladder rows
- wrapped answer text rather than single-line overflow
- figures constrained to their semantic pane
- no learner-facing production/audit jargon
- zero out-of-bounds text blocks and zero severe overlap flags in the final automated scan
