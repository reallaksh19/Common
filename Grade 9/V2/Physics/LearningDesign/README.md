# PHY-V2-04 Physics Learning Design

This directory owns **how** the frozen PHY-V2-03 `LearnerStudyModel` is taught. It preserves every upstream engagement/readiness decision and obligation while adding Physics-specific instructional choreography.

The central journey is phase-state handoff reasoning: represent the boundary state, predict what persists, reconstruct terminal-state → next-initial-state continuity, contrast a state reset with a valid handoff, then fade support toward non-isomorphic transfer and physical verification.

Probe-first targets begin with their exact canonical diagnostic probe. Static authored support assets are separate from live `InteractionSupportState`; runtime may select only pre-approved assets. No page/layout, scheduling, or PR #156 content belongs here.
