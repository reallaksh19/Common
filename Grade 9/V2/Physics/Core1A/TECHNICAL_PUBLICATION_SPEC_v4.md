# Physics Core1A Technical Publication Spec v4 — SDU + Concept TTU v3

Core1A is the declarative-dominant realization of the **Study Differentiation Unit (SDU)**. It teaches the complete conceptual model for a subtopic/SBA bucket. Student knowledge percentage does not control authored depth.

## Authority path

`ground truth / validated Core chain → canonical domain registry → CDAU → SDU → Concept TTU → Core1A publication`

Core1A may not invent source truth, alter frozen Core2 wording, or use learner-performance claims as teaching authority.

## Difficulty and depth

The bucket receives one intrinsic `EASY | MEDIUM | HARD` badge from SDU evidence or explicit bounded owner override.

The corresponding `~10 / ~20 / ~30` page values are **soft maximum depth envelopes**, shared with Core1B but not quotas. Core1A and Core1B derive actual length independently. Same badge does not imply same pages, examples, diagrams, text, or learner action.

## Concept TTU realization

Every major inferential jump in Medium/Hard material must be represented by a Concept TTU whose canonical expert state binds:

`physical idea / setup → technical representation → governing relation → representation/relation mapping → reasoning chain → conclusion → independent verification`

The TTU must declare stable semantic elements and reasoning-state transitions. A technically correct diagram alone is not closure.

## Downstream reconstruction is authored upstream

Even though Core1A normally renders the complete expert state, the underlying Concept TTU must define one or more legitimate Core1B learner transformations selected from:

`PREDICTION | COMPLETION | GENERATION | SELECTION | DISCRIMINATION | DIAGNOSIS | DERIVATION_CONNECTION | VERIFICATION`

Core1B therefore transforms an authorized conceptual state rather than inventing arbitrary blanks, a different model, or a new canonical answer.

## Duplication control

Every worked teaching example must have a CDAU example fingerprint covering problem family, context, givens, numeric values, target, representation, model sequence, special condition and solution path.

Fundamental equations and definitions may recur as `SEMANTIC_REUSE`. Exact explanatory prose, numeric worked states, diagrams and solution paths may not be mirrored into Core1B unless the lineage is explicitly `FADING_ANCHOR` or another allowed pedagogical transformation.

## Required self-help closure

A substantial Concept TTU must expose, where applicable:

- complete model conditions;
- representation-to-equation binding;
- intermediate reasoning, not only final equations;
- misconception contrast;
- at least one check independent of the answer key;
- a repair target for the corresponding B-layer transformation.

## Publication gate

Core1A release requires CDAU `G_DOMAIN`, `G_PURPOSE`, `G_DIFFERENTIATION`, SDU `G_DIFFICULTY`, TTU `G_TTU`, and publication/layout gates. Successful PDF generation is not a visual pass.
