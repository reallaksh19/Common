## Controlling meaning

| Layer | Responsibility |
|---|---|
| Core1 | Correct, connected subject knowledge: concepts, prerequisites, laws/models, equations/reactions, reasoning and validity. |
| Core2 | Analysis of source questions: cognitive demands, representations, solution approaches, misconceptions, coverage and assessment uncertainty. |
| Core1A | Detailed assimilation of difficult concepts using small justified steps, pictures, real-life examples, simplified explanations and unpacked equations/reactions. |
| Core2A | Owner-directed question experience from the very simplest questions to competitive-exam readiness. Knowledge percentage informs support; it does not set the owner's goal. |

The unit of execution is the subtopic. A relay bundle carries one to three subtopics; each can require many teaching atoms. Packets must preserve useful intellectual work while fresh receiving instances independently validate claims against source evidence.
