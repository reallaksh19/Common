## What to retain from the current subject work

Physics: explicit SBA/atom/question links and hint-support granularity. Mathematics: exact learner-policy bindings, shared-prerequisite homes and meaningful reference invariants. Chemistry: source and answer closure, exact frozen artifacts, and machine-versus-human acceptance separation. See [pinned evidence](pr-evidence.md).

These are architecture anchors, not a recommendation to merge any of the three PRs. Their full behavior and CI were not reviewed here.

## Open design choices

- Which actual profiles demonstrate subject and assimilation competence on unseen topics? No empirical ranking is available.
- What packet working set minimizes lost reasoning while controlling retrieval and context costs? No universal token cap is justified.
- Which content claims can receive reproducible automated checks and which need independent expert judgment in each subject?
- How should the production system operationalize partial release when one subtopic is blocked but another is complete?
- Which source-preservation policies must remain mandatory in the archive while owner-specific products select subsets?
- What sufficient evidence is needed before automatically accepting a pedagogical review, if automation is desired?
- How much rework is tolerable under different owner budgets, and when does unresolved evidence require a narrower product?

This review supplies a coherent candidate contract and falsifiable cases. It does not turn these open questions into implementation trivia or claim that a mediocre agent is guaranteed expert-level teaching.
