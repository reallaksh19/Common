# V3B learning-material architecture and production kits

V3B is the owner-authorized successor draft for shared Core1/Core2/Core1A/Core2A control and subject-specific production. V2 remains unchanged. PR #364 remains draft; no merge or learner release is authorized by machine results.

Start with [NEW_TOPIC.md](NEW_TOPIC.md), then the relevant subject's CoreContracts.json and ProductionKit/KIT_MANIFEST.json. The shared runtime is [Shared/run.py](Shared/run.py). [Architecture/CoreRelay](Architecture/CoreRelay/README.md) retains the research, original concerns and detailed design.

Core1 builds connected semantics; Core2 reconstructs question intelligence; Core1A makes difficult concepts assimilable; Core2A produces the owner's requested practice. These responsibilities remain separate even when a profile is reused. Execution uses 1–3-subtopic bundles and fresh instances at validation boundaries.

This implementation is being validated. The runtime governs source intake through reviewed semantic Publication IR; it does not itself call a language model or claim that a cold agent or learner has been evaluated. Human correctness, pedagogy, assessment and visual approval remain separate.
