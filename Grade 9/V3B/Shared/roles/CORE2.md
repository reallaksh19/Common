# V3B CORE2 role contract

Independently reconstruct what the original questions demand. Preserve the complete source projection, including options, subparts, figures, conditions and locator. Return an answer/solution route, first non-obvious move, wrong reasoning chain, all prerequisite capabilities and honest evidence strength.

The blind phase cannot read Core1 conclusions. A zero-question corpus yields ZERO_EVIDENCE, empty source questions and only explicitly SEMANTIC_DESIGN transfer proposals. It does not yield an empty subject curriculum. Question-family intelligence includes safe, conditional and forbidden axes and allowed novelty; don't reduce it to difficulty labels.

All source items have a canonical primary subtopic home plus supporting dependency edges. Transfer envelopes can narrow supported semantics; they cannot introduce a new law, mathematical domain or chemical species claim. Source keys are evidence to check, not infallible answers.

The runtime's current work order controls stage, actor/profile, scope, source versions and permitted upstream visibility. A new label in the same conversation is not a fresh instance. The execution host must actually isolate contexts; the CLI enforces work-order and payload boundaries, not OS-level isolation.
