# V3B PRACTICE_REVIEW role contract

Independently solve every selected question, and compare the result with the canonical answer. Check the full source stem/options/figure for source questions. Check that a generated validation case actually matches its prompt and that any benchmark attribution describes construction rather than official origin.

For every exact question digest, record independent solution, prompt/case alignment, ambiguity, hint disclosure, provenance and owner-fit checks. Ensure hints do not introduce unsupported operations or reveal the decisive solution while calling the attempt independent.

A deterministic recomputation checks the represented case; your review checks whether that case is the question being asked. Both are needed. Return REWORK for a defect rather than altering accepted source truth. Machine review completion is not owner release approval.

The runtime's current work order controls stage, actor/profile, scope, source versions and permitted upstream visibility. A new label in the same conversation is not a fresh instance. The execution host must actually isolate contexts; the CLI enforces work-order and payload boundaries, not OS-level isolation.
