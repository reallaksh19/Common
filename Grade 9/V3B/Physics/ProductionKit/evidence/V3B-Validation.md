## Deliberate corruptions detected

- Changed visible numerical answer while leaving the calculator untouched, including a resealed file digest.
- Deleted answer body while retaining its answer anchor and resealing the file digest.
- Changed frozen source bytes; separately, changed and legitimately rebound source values without updating the candidate answer.
- Changed the equation operation, omitted a required question/Core/source-atom realization, removed solution steps, or changed the original question number.
- Dropped original options/conditions; supplied an unsupported original figure that otherwise could have been silently omitted.
- Bound a figure to an unassigned source atom, tampered with the exported SVG, or chose a graph range that hides observations.
- Omitted a runtime dependency from both disk and manifest; forged an academic/visual PASS field.
- Used a stale baseline, attempted to overwrite an existing publication, or requested an unsupported scientific evaluator.
- Omitted required knowledge provenance. Study-only mode still ignores practice percentage controls.

Positive controls cover equivalent numeric formatting, intentional reconstruction reuse, properly labelled owner-waiver routing, valid graph/vector rendering, and deterministic relocation. A declared numeric variant receives a transfer-review flag rather than new-transfer approval. Full semantic similarity and independent transfer adjudication remain pending.

One intermediate test failed because the fixture shared the same mutable list between its baseline and authored plan: adding a missing obligation also accidentally added its ID to the candidate. The fixture now returns independent serialized copies. The expected failure was retained; no production check or tolerance was weakened to make the test pass.

## Publication and geometry observations

Initial figure inspection found excess horizontal canvas in vector diagrams and weak readability of a small temperature change on a zero-based Kelvin axis. The reusable renderer now sizes vector canvases from their geometry while retaining equal x/y scale, paints an explicit white background, uses bold vector symbols, and supports a source-bound labelled graph minimum. Final standalone SVGs were inspected after this change. Full HTML/MathML browser layout, pagination and print margins remain unverified.

The final packet's basis, runtime and archive digests are recorded in V3B-Proof-Manifest.json. V3B-Publication-Proof.zip contains the exact generated HTML/SVG, owner/evidence board, source and input JSON, file manifest, and command/runtime policy snapshot. It is a reproducible engineering specimen, not a mature learner chapter.

## Code and authority review

Production modules separate source/obligation validation, scientific result checking, figure geometry, composition, exported-file audit, filesystem persistence and CLI dispatch. Each has a live publish/verify consumer. No V2 imports, topic/question IDs in production, or duplicate Physics calculation implementation were introduced. The existing Physics validator and Shared runtime files remain unchanged.

All new production modules are below 300 physical lines. The exported-publication audit is one cohesive ordered verification function slightly above the 40-line review trigger: it binds input/runtime authority, reads candidates, verifies file custody and checks the owner projection. Its failure ordering is tested; splitting it further was not needed for this bounded host. All mutations occur through the explicit output-directory transaction. Review flags cannot become learner-release authority.

The source data adapter accepts declared structured JSON, not arbitrary source scans. It checks identity and completeness against supplied baseline records but cannot establish extraction accuracy or academic sufficiency. Unknown source-question fields are held. Existing six-Core depth, calibrated similarity, observed learner fit, independent reviewer acceptance and transitive authoring-extension requirements remain open, as detailed in ../V3B-Runtime-Map.md.
