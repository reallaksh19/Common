## Deliberate boundaries

The production checker resolves actual supplied content objects and compares them with the declared expected baseline. It does not parse arbitrary prose into scientific meaning, resolve external URLs, verify source file bytes, authenticate an owner/reviewer, or infer learner mastery. Those functions require trusted source custody and review adapters. Fake claims with the right shape must never be labelled human-approved.

Current numeric checks are exact analytical specimen checks, not a general Physics solver. Text-only frozen-source test records are synthetic process fixtures. No real frozen Thermodynamics exam corpus was supplied or audited.

Similarity corpus calibration, external independent reviewer labels, topic badge validation, learner-fit evaluation and cold-agent continuation trials are NOT_RUN. No thresholds have been promoted beyond ENGINEERING.

Node CLI invocation, browser execution/visual inspection, native PDF generation and actual-size visual preflight are NOT_RUN in this environment. The JavaScript engine was executed directly, not represented as a Node/browser run. SVG coordinates and intended semantics are authored; readability/overlap still require actual render inspection.
