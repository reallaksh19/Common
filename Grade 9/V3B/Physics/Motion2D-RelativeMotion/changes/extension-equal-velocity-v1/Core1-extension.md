# Core 1 extension — B05E equal velocity, different starting positions

<a id="b05e-equal-velocity-different-initial-position"></a>
## B05E quick note

If `v_A/G = v_B/G`, then `v_A/B = 0`. This means the relative position **does not change**. It does **not** mean the relative position is zero. Keep the starting gap.

**Quick check — EXT-C1-Q01.** A is 7 m east of B and both move east at 2 m/s. What is their separation 9 s later?  
**Answer:** 7 m. They gain the same displacement, so the initial 7 m relative position remains constant.
