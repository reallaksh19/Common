## C. 50%-knowledge gate

For each supplied question mark PASS/FAIL:

| Q | Prerequisite refresh | Recognition cue | First useful step | Execution bridge | Error/legality check | Question has no answer leakage | Overall |
|---:|---|---|---|---|---|---|---|
| | | | | | | | |

A question is overall PASS only if every required field passes.

Do not let the attachment redefine the curriculum by omission.

## E. Appendix checks

### Appendix A

- [ ] all supplied questions present;
- [ ] no question silently rewritten;
- [ ] only question text in the appendix;
- [ ] no worked solution;
- [ ] no inline answer;
- [ ] answer key after final question;
- [ ] source notes stored separately.

### Appendix B

- [ ] requested mock count present;
- [ ] author-created items labeled as such;
- [ ] historical mechanisms used only as style references unless verbatim authority is intended;
- [ ] all answers independently recomputed;
- [ ] answer key after final mock question;
- [ ] underrepresented canonical skills included.

## F. Quick-reference check

- [ ] 1–2 page target;
- [ ] only high-value formulas/facts;
- [ ] hypotheses/legal-use conditions included;
- [ ] no long worked solutions;
- [ ] terminology matches main guide.

## G. Citation/provenance check

- [ ] every historical official claim has a repository/official citation;
- [ ] comparison-source uncertainty preserved;
- [ ] source ledger kept outside questions-only appendix;
- [ ] author-created items clearly marked;
- [ ] no official Grade-9-only IOQM syllabus/weightage invented.

## H. Final status

Use one of:

- `STATIC_CONTENT_SELF_SUFFICIENCY = FAIL`
- `STATIC_CONTENT_SELF_SUFFICIENCY = PARTIAL_n_OF_N`
- `STATIC_CONTENT_SELF_SUFFICIENCY = PASS_N_OF_N`

Keep separate:

- classroom timing/readability: `NOT_RUN` unless observed;
- learner solve rate: `NOT_RUN` unless tested;
- retention: `NOT_RUN` unless tested;
- psychometric calibration: `NOT_RUN` unless measured.

## I. Final reviewer question

For every question ask:

> If the learner had only this guide, ordinary Grade 9 school mathematics and enough time, would the missing step be **reasoning** or would it be an **untaught trick**?

Reasoning is acceptable. An untaught trick is a guide defect.
