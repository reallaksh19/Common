# Sequence & Series First-Step Reference Specification

## Purpose

Train independent problem recognition before calculation.

Required routine:

`SEE -> REALIZE -> WRITE -> CHOOSE -> CHECK`

- **SEE** — identify the visible pattern/operation.
- **REALIZE** — name the invariant or promising transformation.
- **WRITE** — translate the problem into `a`, `d`, `r`, `n`, `S_n`, sigma, recurrence, or transformed sequence.
- **CHOOSE** — select the cleanest relation/move.
- **CHECK** — verify sign, scale, number of terms, conditions and consistency with the original pattern.

## Required recognition cards

- AP: difference / nth term / block sum.
- GP: ratio / selected terms / finite vs infinite.
- HP/means: reciprocal transform / midpoint relations.
- Sigma/power sums: counter, expansion, splitting, inner-sum collapse.
- Telescoping: partial fractions / rationalization / neighboring cancellation.
- Reverse-from-sum: `a_n = S_n - S_{n-1}`.
- Finite differences: quadratic/cubic pattern recognition where appropriate.

## Contrast pairs

Use near-neighbor prompts such as:

- sequence vs series;
- AP vs GP using similar opening terms;
- `a_10` vs `S_10`;
- finite GP vs infinite GP;
- AP vs HP after reciprocation;
- direct power sum vs nested power sum;
- odd/even split vs brute-force expansion.

## Hint ladder

For bridge questions, reveal in stages:

1. recognition cue;
2. representation/transformation;
3. setup/equation;
4. final calculation only in the solution section.

The learner should stop when the first sufficient hint is reached.

## JEE bridge

Use the B1-B18 set in `Sequence_Series_JEE_Bridge_Map.md`. The bridge should remain external extension material and should not be represented as handwritten-source content.

## Success criterion

For a mixed unseen question, the learner can write the first useful line and justify why that move fits the structure before carrying out the calculation.
