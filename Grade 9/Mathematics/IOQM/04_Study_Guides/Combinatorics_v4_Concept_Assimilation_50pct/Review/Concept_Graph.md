# Combinatorics concept graph - assimilation first

## Governing rule
Student structure follows recognition, representation, first move, legality and transfer. Appendix A audits coverage; question order does not determine teaching order.

## Main spine
`counted object + identity rule -> choose restriction strategy -> choose representation -> first counting skeleton -> exact-once / boundary / symmetry check -> transfer`

## Nine journeys
1. **Counted object and identity before formula** - ordered vs unordered; labelled positions vs quotient by symmetry.
2. **Build restrictions into the construction** - direct construction, complement, inclusion-exclusion and verbal-logic case diagrams.
3. **Repeated objects and distributions** - stars-and-bars, lower-bound shifts, copy-count/generating models and multiplicity patterns.
4. **Local restrictions in a line** - blocks, gaps, derangements, chained bad events and exact adjacency.
5. **Circular identity and symmetry** - ordinary round tables, numbered seats, circular gaps, necklace/bracelet orbit legality.
6. **Pairwise restrictions become graphs** - handshake, conflict graphs, proper colouring, perfect matching and degree-2 cycle decomposition.
7. **State is the smallest memory the future needs** - recurrence, state sufficiency, reverse state, change encoding and first-stable-prefix decomposition.
8. **Arithmetic surfaces become exponent/residue representations** - divisor exponent grids and residue-class compression.
9. **Capacity and invariants** - pigeonhole boxes/capacity and losing/winning game states.

## Important decision boundaries
- direct construction vs complement;
- complement vs inclusion-exclusion;
- stars-and-bars vs bounded multiplicity;
- block vs gap;
- path colouring vs cycle colouring;
- linear positions vs circular identity;
- divide by symmetry vs orbit/fixed-point audit;
- remaining length only vs sufficient recurrence state;
- forward recurrence vs reverse state;
- static count vs adversarial game-state analysis.

## Cross-links
`identity -> symmetry legality`

`restriction strategy -> block/gap/graph/state representation`

`graph degree -> cycle decomposition -> circular identity checks`

`state memory -> residue/game invariant states`

`bounded multiplicity -> exponent-grid viewpoint`

`pigeonhole capacity -> extremal impossibility / forced collision`

## Learner mastery
Planning profile is approximately 50% prior knowledge. Actual mastery remains unassessed until unaided recognition and first-move evidence is collected.
