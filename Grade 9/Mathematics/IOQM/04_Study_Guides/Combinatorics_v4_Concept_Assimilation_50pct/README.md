# IOQM Grade 9 Combinatorics - Concept Assimilation 50% Edition

This package is the full concept-assimilation rebuild layered on top of the existing `Combinatorics_v3` visual guide and repository topic streams.

## Learner model
Planning profile: approximately 50% prior knowledge. Formula recall may exist; method recognition, representation choice, exact-once reasoning, symmetry legality and transfer are not assumed.

## Governing learner chain
`UNDERSTAND -> RECOGNIZE -> REPRESENT -> START -> EXECUTE -> CHECK -> TRANSFER`

- Appendix A: Q1-Q56, stable numbering preserved
- Appendix B: B1-B20, author-created mixed transfer; not relabelled as official PYQ
- repository question-to-method audit reused rather than recreated
- static Appendix A support: `PASS_56_OF_56`
- priority split retained: MUST 22 / SHOULD 24 / IF TIME 10

## Assimilation architecture
The new student front end uses nine linked journeys rather than question order:
1. counted object and identity before formula;
2. direct construction / complement / inclusion-exclusion / verbal logic;
3. identical distributions and bounded multiplicity;
4. blocks / gaps / derangements / exact adjacency;
5. circular identity and symmetry;
6. graphs / matchings / colourings / degree-to-cycle structure;
7. recurrence, state memory and change encoding;
8. prime-exponent and residue representations;
9. pigeonhole, games and invariants.

## Repository reuse
The rebuild searched and reused the existing COMB-01, COMB-02, COMB-03 and COMB-05 topic streams plus the Combinatorics v3 Navigator, visual pedagogy material and question-to-method/priority matrix. COMB-04 games/invariants remains an explicit bridge/transfer layer rather than being falsely presented as a complete production stream.
