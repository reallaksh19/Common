## What changed from v1

The first version grouped the 56 questions correctly at a high level but was too compressed to support a claim of self-sufficiency for a half-prepared learner. v2 explicitly repairs the missing execution steps, including:

- derangements;
- bounded generating-function coefficient extraction;
- alternating-permutation enumeration;
- first-stable-prefix recurrence;
- labeled cycle decomposition;
- exact-adjacency counting;
- perfect-matching recursion;
- necklace/reflection symmetry;
- self-referential subset-size conditioning.

It also adds the wider IOQM combinatorics skills that the attachment underrepresents:

- pigeonhole and extremal reasoning;
- invariants and elementary game strategy.
