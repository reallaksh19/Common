# IOQM Grade 9 — Study Guides

Student-facing study guides in this folder combine the existing Grade 9 IOQM curriculum with additional practice/reference material without creating new main-topic ownership.

## Canonical Combinatorics Study Guide — v2

Start with [`Combinatorics_v2/README.md`](Combinatorics_v2/README.md).

The v2 rebuild was triggered by a ground-reality audit of whether a Grade 9 student with roughly 50% prior knowledge could execute the methods needed for all 56 supplied questions.

The earlier v1 grouping was broadly correct, but several advanced moves were too compressed. v2 explicitly repairs derangements, bounded generating-function extraction, alternating-permutation enumeration, first-stable-prefix recurrence, labeled cycle decomposition, exact-adjacency counting, matching recursion, necklace/reflection symmetry and subset-size conditioning.

It also restores wider canonical IOQM combinatorics coverage underrepresented by the attachment:

- pigeonhole and extremal reasoning;
- invariants and elementary game strategy.

### Appendix A — supplied questions

[`Appendix_A_Q1-Q56.md`](Appendix_A_Q1-Q56.md) remains the canonical clean question appendix. It contains all 56 supplied questions, with source/module/tip/solution commentary removed and the answer key only after Q56.

The Q42 wording uses the coherent “successive teachers in the row” interpretation supported by the attached compilation's own source-solution note; the separate v2 source ledger preserves that caution.
