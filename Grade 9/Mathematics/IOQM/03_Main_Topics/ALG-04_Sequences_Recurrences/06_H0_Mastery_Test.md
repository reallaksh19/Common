# ALG-04 — Independent Mixed Mastery Check

No default hints and no method labels. First attempt is independent.

## Part A — Notice and first line

1. The partial sums are `S_n=4n^2+n`. Write the first useful line for finding `a_n`.
2. Every 6-term sum is greater than the preceding 6-term sum. Write the first useful line.
3. `a_n=2^n+3`. The target is `a_50`. State why no recurrence iteration is needed.
4. `a_{n+2}=5a_{n+1}-4a_n`. The target is a high-index term. Write a useful transformed relation before computing terms.

## Part B — Full mixed solve

5. The partial sums are `S_n=4n^2+n`. Find `a_n`.
6. `a_1=1,a_2=4` and `a_{n+2}=5a_{n+1}-4a_n`. Find `a_8` efficiently.
7. Evaluate `sum_{k=1}^{50} 1/[k(k+1)]`.
8. Every 4-term sum is equal to the preceding one. If
   `a_1=1,a_2=2,a_3=4,a_4=8`,
   find `a_99`.
9. Let `b_0=0,b_1=1`,
   `b_{n+2}=-4b_{n+1}-7b_n`,
   and `D_n=b_n^2-b_{n-1}b_{n+1}`.
   Find `D_20` without computing `b_20`. Stop at the invariant result; divisor-count doctrine is outside this topic.

## Part C — Same surface, different decision

10. Sequence A: `2,6,10,14,...`.  
    Sequence B: `2,6,18,54,...`.  
    State the invariant that classifies each.

11. Representation A: `a_n=3n+1`.  
    Representation B: `a_{n+1}=a_n+3`, `a_1=4`.  
    Identify explicit versus recursive form and state why the initial value is necessary in B.

12. Compare:
    - `sum_{k=1}^{n} 1/[k(k+1)]`;
    - `sum_{k=1}^{n} 1/(k^2+1)`.
    Explain why the first has an immediate neighboring-term telescope but the second should not be declared telescoping from appearance alone.

## Part D — Changed-surface transfer

13. A shop records daily sales `r_1,r_2,...`. Every 5-day rolling total is larger than the preceding 5-day total. Prove the corresponding term inequality.

14. Machine readings satisfy
    `x_{n+2}=2x_{n+1}+3x_n`.
    Define
    `Q_n=x_n^2-x_{n-1}x_{n+1}`.
    Derive the recurrence for `Q_n`.

## Part E — WHY-NOT and verification

15. A proposed explicit formula agrees with the first five terms generated by a recurrence. Explain why this alone is not a proof, and state the complete verification test.

16. A student sees a tiling count with the recurrence `t_n=t_{n-1}+t_{n-2}` and says, “It is Fibonacci, so the recurrence is proved.” Explain precisely what must still be established before the recurrence is valid for the counting problem.

## Ownership check

For any two problems above, state:
- the visible clue;
- the hidden structure;
- the first useful line;
- one tempting but inferior or invalid nearby method.
