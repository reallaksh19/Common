# Recognition and First-Line Lab

For each item, write only the **best first move** or choose the best option. Do not complete a long solution unless needed to justify the choice.

## Recognition

1. `8^(x-1)=4^(x+2)`. What is the cheapest representation?
   A. decimal approximations  B. common base 2  C. take square roots  D. expand powers

2. Which statement is always correct for real `x`?
   A. `sqrt(x^2)=x`  B. `sqrt(x^2)=-x`  C. `sqrt(x^2)=|x|`  D. `sqrt(x^2)=x^2`

3. Before squaring `sqrt(U)=V`, which condition is essential for a reversible square?
   A. `V<=0`  B. `U<0`  C. `U>=0` and `V>=0`  D. `U=V`

4. Which expression most strongly suggests a conjugate as the first tool?
   A. `2^x=16`  B. `1/(sqrt7-sqrt5)`  C. `sqrt(x+4)=3`  D. `log_2 8`

5. What must be preserved in `sqrt(x-sqrt(x+a))`?
   A. treat it as `sqrt x-sqrt(x+a)`  B. the inner radical as part of the outer radicand  C. only the outer square root  D. only the integer condition

6. You square an equation without first proving both sides have the same known sign. What is safest to record?
   A. the square is automatically equivalent  B. the square may generate candidates, so check the original  C. no domain is needed  D. every quadratic root is valid

7. For `log_(x-2)(x+1)`, which domain conditions belong to the first line?
   A. `x+1>0` only  B. `x-2>0`, `x-2!=1`, `x+1>0`  C. `x-2!=0` only  D. `x>0` only

8. If `a,b>1` and both reciprocal logarithms occur, which compression is useful?
   A. `t=a+b`  B. `t=log_a b`, so `log_b a=1/t`  C. `t=ab`  D. `t=log_a a`
