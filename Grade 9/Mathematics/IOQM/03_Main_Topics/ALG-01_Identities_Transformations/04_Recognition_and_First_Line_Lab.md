# ALG-01 — Recognition and First-Line Lab

Write only the first useful line.

1. Evaluate `103^2-97^2`.
2. Simplify an equation containing three occurrences of `x+1/x`.
3. Given `a+b=7`, `ab=10`, find `a^2+b^2`.
4. Given `x^2=4x-2`, find `x^5` efficiently.
5. Solve `sqrt(x+3)=x-1`: what condition must be written before squaring?
6. Solve `(x-2)(x+5)=0`: should you expand first?
7. Given `u-v=3` and `uv=10`, find `(u+v)^2` without solving `u,v` individually.
8. Equation `(x-1)/(x+2)=3`: what value must be excluded before clearing the denominator?
9. Given `t^2+t+1=0`, write the simplest reduction for `t^3`.
10. You want `p^3+q^3` and know `p+q` and `pq`. Write the identity you would use.

For each item also label the decision: `FACTOR`, `EXPAND`, `SUBSTITUTE`, `SYMMETRY`, `POWER_REDUCE`, `DOMAIN_CHECK`.
