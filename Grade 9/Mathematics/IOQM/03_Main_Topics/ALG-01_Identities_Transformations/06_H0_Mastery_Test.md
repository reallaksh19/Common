# ALG-01 — H0 Mastery Test

No default hints or method labels.

1. Evaluate `1007^2-993^2`.
2. If `a+b=13` and `ab=36`, find `a^3+b^3`.
3. If `x^2=2x+5`, express `x^5` as `Ax+B`.
4. Given `p-q=4` and `pq=21`, find `p^2+q^2`.
5. Solve `sqrt(3x+4)=x+2`, preserving all domain and candidate checks.
6. Let `y+1/y=5`. Find `y^3+1/y^3` without solving for `y`.
7. If `u^2+u+1=0`, determine `u^2026`.
8. An equation contains `(x^2+3x)` repeatedly. Describe a substitution that lowers structural complexity and state one condition for when such a substitution is useful.
9. Explain why dividing `x(x-4)=0` by `x` is not an equivalent transformation.
10. Construct a pair of expressions where expanding is the efficient first move in one and factoring is the efficient first move in the other; justify each choice.

For any two computational items, also state the clue that determined the first move.
