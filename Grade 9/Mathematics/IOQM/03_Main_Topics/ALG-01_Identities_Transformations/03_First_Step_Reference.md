# ALG-01 — First-Step Reference

## Recognition atlas

| Visible structure | First question |
|---|---|
| difference of squares | factor? |
| repeated composite block | substitute? |
| symmetric target in two variables | rewrite via sum/product? |
| high power + low-degree relation | reduce powers? |
| radicals/denominators then squaring/clearing | what domain/equivalence check? |
| target already close to a known identity | reconstruct rather than solve? |

## Quick router

```text
TARGET first
  |
  +--> product/zeros -> factor
  +--> coefficient form -> expand
  +--> repeated block -> substitute
  +--> symmetric target -> use invariants
  +--> high power + low-degree relation -> reduce
  +--> non-reversible step -> record/check candidates
```

## First-step cards

### Factor vs expand
Choose the direction that makes the requested target shorter.

### Substitution
Name only a block that genuinely repeats.

### Symmetry
Swap the variables mentally. If the target is unchanged, individual values may be unnecessary.

### Relation reduction
Write the highest available power as a lower-degree expression and reuse it.

### Equivalence
After squaring/dividing/clearing denominators, verify candidates in the original condition.

## Contrast strip

- identity vs solution-only relation;
- solving variables vs evaluating a symmetric expression;
- reversible step vs one-way implication;
- algebraic transformation here vs Vieta/discriminant canon in ALG-03.
