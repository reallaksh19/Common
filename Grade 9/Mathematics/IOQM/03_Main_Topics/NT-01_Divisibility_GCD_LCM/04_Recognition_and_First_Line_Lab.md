# NT-01 — Recognition and First-Line Lab

Do not fully solve unless asked. Write only the **first useful mathematical line**.

1. Greatest integer dividing 188 and 296 with the same remainder.
2. Least positive integer divisible by 14, 20 and 35.
3. Compute `gcd(12345,5432)` efficiently.
4. `gcd(a,b)=9`, `lcm(a,b)=252`. Write an invariant involving `ab`.
5. A divisor `d` divides both `5x+7y` and `2x+3y`. Write one useful linear combination also divisible by `d`.
6. A number gives remainder 4 modulo each of 6, 10 and 15. Write the first line for the least such number above 4.
7. Find the greatest divisor that leaves the same remainder when dividing 812, 1046 and 1280. Write only the reduction.
8. Two alarms ring every 18 and 24 minutes. Write only the operation that gives the next common ringing time.
9. `a=gu, b=gv` with `g=gcd(a,b)`. What extra condition must `u,v` satisfy?
10. Decide whether `84|1260` by translating divisibility to an integer quotient statement.

## Recognition-only labels

For each item above, label one of:
`DIVISIBILITY`, `DIFFERENCE_GCD`, `EUCLID`, `LCM`, `GCD_LCM_PRODUCT`, `LINEAR_COMBINATION`.

No method label should appear in later H0 mastery items.
