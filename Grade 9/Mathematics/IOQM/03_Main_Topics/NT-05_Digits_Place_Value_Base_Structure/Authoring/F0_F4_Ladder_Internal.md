# Internal F0-F4 Ladder

- F0: learner identifies the arithmetic target without a method label.
- F1: learner chooses place-value/block/carry/product representation.
- F2: learner writes the first useful line independently.
- F3: learner completes the arithmetic restriction and checks digit/base conditions.
- F4: learner transfers to a changed surface and hands counting off only when required.

Internal only; these labels are not exported to learners.
