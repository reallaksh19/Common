# Practice and Transfer Bank

Attempt each item before consulting the Teacher Diagnostic Key. Items 1-8 reconnect core moves, 9-16 combine filters, and 17-24 change representation or context.

1. Find all positive integer pairs x,y with xy=36 and x+y minimal.
2. Solve positive integers (x-2)(y+3)=20; give the number of solutions.
3. Find positive integers x,y satisfying xy=84 and gcd(x,y)=1; how many unordered pairs?
4. Find the greatest integer n for which n(n+1)<90.
5. How many integers x satisfy x^2-5x+6=0?
6. Find all integer x with x^2=3x+10; return the sum of solutions.
7. A reduced fraction a/b differs from 2/3 by 1/30 and b>0. Find a+b for the smaller fraction.
8. Find the least positive denominator b for a fraction strictly between 3/7 and 4/9.
9. Find integer solutions to x+y=11, xy=24; give |x-y|.
10. If x+y=14 and xy=48 for integers x,y, find x^2+y^2.
11. How many integer x make x^2+4x+7 a perfect square <=16?
12. For integer n, when is n^2+n odd? Return 0 if never, 1 otherwise.
13. Find the number of positive integer pairs x<=y with 1/x+1/y=1/2.
14. Positive integers x,y satisfy x^2-y^2=45 and x>y. Find the number of solutions.
15. Find the greatest possible gcd(x,y) if x+y=72 and xy is divisible by 100.
16. Find integer n such that n^2+6n+5 is a square and |n|<=10; how many n?
17. A rectangle has integer sides and area 96. Find its least perimeter.
18. Find the least positive |4a-5b| for integers 1<=b<=12 with gcd(a,b)=1 and a/b !=5/4.
19. How many positive integer triples a<=b<=c have abc=30?
20. Find all integer x with `(x-1)(x+4)=24`; return the product of the solutions.
21. If t^2-St+P=0 has integer roots and S=9,P=14, find the larger root.
22. How many integer x make x(12-x) positive and divisible by 5?
23. Positive integers x,y satisfy xy=2^6*3^2 and gcd(x,y)=1. How many ordered pairs?
24. Find the number of integers k with 0<=k<=20 for which k^2-7k+10 is even.

## Reflection after the bank
For any item that took more than one false start, record: visible clue, first line you tried, cheaper filter you missed, and the final condition that certified the answer.
