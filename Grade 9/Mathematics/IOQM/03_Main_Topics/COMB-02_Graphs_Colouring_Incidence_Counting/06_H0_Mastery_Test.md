# Mixed Mastery Test

Solve each problem without method labels or hints. Define the counted object or graph clearly whenever the representation is not already explicit.

1. A graph has degrees `3,3,2,2,2,2`. Determine the number of edges.

2. Decide whether a graph can have degree sequence `4,4,3,3,3,2`. Justify.

3. A path with five labelled vertices is properly coloured using four available colours. Determine the number of colourings.

4. Determine the number of proper colourings of a 4-cycle using three available colours.

5. A graph is `K4` with exactly one edge removed. Determine the number of proper colourings using four colours.

6. Determine the number of unordered knight-move pairs on a `4 x 4` board.

7. Ten clubs each contribute six student-membership incidences. Every student belongs to exactly three clubs. Determine the number of students.

8. Eight labelled positions lie on a cycle and three named colours are available. Every three consecutive positions must have pairwise distinct colours. Determine whether a valid colouring exists and justify your conclusion.

9. Prove that every red/blue colouring of the edges of `K6` contains a monochromatic triangle.

10. Twelve lines each contain exactly four selected points. Every selected point lies on exactly three of the lines. Determine the number of selected points.

11. A directed graph records all legal moves of a two-player game. Explain why counting outgoing edges alone is not enough to determine a winning strategy, and name at least two additional pieces of state information that may matter.

12. Determine the number of proper colourings of a 7-cycle using three available colours.
