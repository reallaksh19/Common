# W1-G — Historical Source and PYQ Audit

## A. Scope boundary
Included: stable IDs, exact source/key authority, independent answer closure, graph-model classification and figure/incidence custody. Excluded: source paraphrase treated as official wording, answer-key-derived “independent” solutions and topic-weightage claims.

## B. Learner-state model
```text
PRIOR_KNOWLEDGE: source-control concepts remain teacher-side.
LIKELY_HALF_KNOWLEDGE: a geometric drawing is simplified to a graph before its exact incidence is checked.
MISSING_BRIDGES: source figure first, graph abstraction second; correct answer does not certify a corrupted model.
OWNERSHIP_TARGET: SOURCE -> INCIDENCE/WORDING LOCK -> GRAPH MODEL -> INDEPENDENT SOLVE -> KEY CHECK.
```

## C. Mathematical invariant / governing structure
Graph abstraction is only valid after source incidence is preserved. Removing an edge, changing cyclic order, or merging/separating a concurrence changes the combinatorics.
