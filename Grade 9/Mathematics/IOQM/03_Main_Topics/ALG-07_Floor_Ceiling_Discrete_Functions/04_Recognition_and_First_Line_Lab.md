# ALG-07 - Recognition and First-Line Lab

Write only the first useful mathematical line unless the item explicitly asks for a value.

1. Evaluate `floor(3.8)` by locating 3.8 between consecutive integers.
2. Evaluate `floor(-3.8)` without truncation.
3. Evaluate `ceil(-3.8)`.
4. `floor(x)=5`. Write the encoded interval.
5. `ceil(x)=-2`. Write the encoded interval.
6. `floor((2x+1)/3)=4`. Write the first inequality chain.
7. `floor(x)<3`. Write an equivalent ordinary inequality.
8. When can `floor(x)=x`?
9. Write the defining first line for the fractional part of `-2.3`.
10. Count integers in `[-2.4,3.1)` by writing the first and last candidate.
11. Simplify `floor(x+7)` without casework.
12. Express `ceil(x)` using floor and reflection.
13. `floor(x)=2` and `x` is an integer. Write the interval before filtering.
14. `floor(x^2)=3`. Write the first double inequality.
15. `floor(x)=ceil(x)`. State the structural condition you should test.
16. For `floor(x)=4`, identify the included endpoint and excluded endpoint.

No method-control labels should appear in later independent mastery items.
