# ALG-07 - H0 Mastery Test

No default hints. No method labels.

## Part A - Notice and first useful line

1. `floor((3x-2)/4)=5`. Write only the first inequality chain.
2. `ceil((x+3)/2)=-1`. Write only the first inequality chain.
3. `floor(x^2)=7`. Write only the first double inequality.
4. How many integers `n` satisfy `-4.2<=n<3.1`? Write only the first and last possible integer.

## Part B - Full mixed solve

5. Solve `floor((2x+1)/3)=4`.
6. Solve `ceil((3x-1)/2)=5`.
7. Solve `floor(x)+ceil(x)=-5`.
8. Solve `floor(x^2)=9`.
9. Find all integers `k` satisfying `floor((k-2)/4)=3`.
10. Find the fractional part of `-2.75`.
11. Solve `floor(x)=ceil(x)`.
12. Characterize all real `x` satisfying `floor(x+0.4)=floor(x)`.

## Part C - Same surface, different decision

13. Solve both `floor(x)=4` and `ceil(x)=4`, then explain why the endpoints differ.
14. Compare `floor(-2.3)` with truncation of `-2.3` toward zero. Explain which definition controls the answer.

## Part D - Transfer and WHY-NOT

15. Seat labels are integers. How many labels lie in the real interval `[12.4,20.0]`?
16. A learner solves `floor(2x)=3` by writing `2x=3`. Explain the defect and give the complete solution set.

## Mastery reflection

For any three solved items, add:
- What interval did the discrete value encode?
- Which endpoint was strict?
- Did the final domain require an integer filter?
- What nearby wrong move was tempting?
- What final endpoint/domain check did you perform?
