# Mixed Mastery Test

Work without method labels or hints. State the domain-sensitive first move clearly.

1. For all real `x`, `2f(x)+f(3-x)=x+9`. Find `f(10)`.

2. For all integers `m,n`,
   `f(m+n)=f(m)+f(n)+mn`
   and `f(1)=1`.
   Find `f(9)`.

3. For all real `x`, `f(x)+f(2-x)=6`. Is `f(5)` uniquely determined? Justify.

4. Suppose `f(x+f(y))=f(x)+y` for all real `x,y`. Prove that equal function values force equal inputs.

5. For all integers `m,n`, `f(m-n)=f(m)-n` and `f(0)=4`. Find `f(13)`.

6. For all real `x`, `3f(x)+f(4-x)=4x+4`. Find `f(7)`.

7. A function on the integers satisfies `f(n+1)=f(n)+2n+1` and `f(0)=0`. Explain why this is a recurrence-like consequence that may help with an integer functional equation, but is not by itself proof of an unrelated two-variable equation.

8. Verify whether `f(x)=x^2+1` satisfies
   `f(x+y)=f(x)+f(y)+2xy-1`
   for every real `x,y`.

9. For all real `x`,
   `f(x)+f(1-x)=5`,
   `f(x)-f(1-x)=2x-1`.
   Find `f(-4)`.

10. A student tries `x=2,3,4` in a functional equation and sees a neat pattern. State the test that separates a useful conjecture from a proof.
