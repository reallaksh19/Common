# Practice and Transfer Bank

Try each item before looking at support. The stages reduce support gradually, but the method names are not supplied inside the questions.

## Stage 0

1. For all real `x`, `f(x)+f(0)=x+2`. Find `f(7)`.

2. For all real `x`,
   `f(x)+f(1-x)=5` and
   `f(x)-f(1-x)=2x-1`.
   Find `f(3)`.

3. For all real `x`, `2f(4-x)+f(x)=x+4`. Find `f(1)`.

4. For all integers `m,n`, `f(m+n)=f(m)+f(n)` and `f(1)=3`. Find `f(-4)`.

## Stage 1

5. A function `f:R->R` satisfies `f(x+1)=f(x)+2` and `f(0)=1`. Explain why these facts alone do **not** determine `f(x)` for every real `x`.

6. For all positive real `x,y`, `f(xy)=x f(y)+y f(x)`. Determine `f(1)`.

7. For all integers `m,n`,
   `f(m+n)=f(m)+f(n)+2mn`
   and `f(1)=1`.
   Find `f(6)`.

8. For all real `x`, `f(x)+f(2-x)=10`. Explain why the equation alone does not determine `f(5)` uniquely.

## Stage 2

9. For all real `x`,
   `f(x)+f(2-x)=10`,
   `f(2-x)-f(x)=2-2x`.
   Find `f(5)`.

10. For all real `x`, `3f(5-x)+2f(x)=x+10`. Find `f(-2)`.

11. For all real `x`, `4f(1-x)+f(x)=3x+1`. Find `f(7)`.

12. For all integers `m,n`,
   `f(m+n)=f(m)+f(n)+mn`
   and `f(1)=1`.
   Find `f(8)`.

## Stage 3

13. A function on the reals satisfies `f(x+f(y))=f(x)+y` for all real `x,y`. Prove that equal function values force equal inputs. (This property is called injective.)

14. For the same equation, prove that every real target occurs as an output by constructing an input for an arbitrary target. (This property is called surjective.)

15. For all integers `m,n`, `f(m-n)=f(m)-n` and `f(0)=3`. Find `f(-11)`.

16. For all real `x`, `2f(x)+f(3-x)=x+9`. Determine `f(20)`.

## Stage 4

17. For all integers `m,n`,
   `f(m+n)=f(m)+f(n)+mn`
   and `f(0)=0, f(1)=1`.
   Derive a formula for `f(n)` for every integer `n`, then verify it in the original equation.

18. A student computes `f(0)=1,f(1)=2,f(2)=3,f(3)=4` and concludes `f(n)=n+1` for all integers. Give a precise reason this conclusion is incomplete and state what would complete it.

19. For all real `x`, `3f(x)+f(4-x)=4x+4`. Determine `f(7)` without guessing a formula from sample values.

20. A proposed function is `f(x)=x^2+1`. Verify directly that it satisfies
   `f(x+y)=f(x)+f(y)+2xy-1`
   for all real `x,y`.
