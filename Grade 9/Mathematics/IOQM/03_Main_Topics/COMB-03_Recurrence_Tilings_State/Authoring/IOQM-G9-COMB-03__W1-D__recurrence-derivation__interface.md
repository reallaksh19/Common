# A. Scope boundary
Owns proving a recurrence from counted states. Supplied-recurrence algebra, AP/GP, telescoping and generic sequence solution methods remain outside this stream.

# B. Learner-state model
Learner can read recurrence notation but may write a plausible relation before defining the state or proving the branches.

# C. Governing invariant / structure
`COUNTED STATE -> DISJOINT + EXHAUSTIVE TRANSITIONS -> SMALLER-STATE CORRESPONDENCE -> BASE MEANING -> RECURRENCE`.

# D. Representation inventory
Scalar recurrence, finite-state vector/table and structural first/last-step decomposition.

# E. Decision boundaries
Given recurrence vs derived recurrence; empirical numerical pattern vs structural identity; scalar recurrence vs state table.

# F. Misconception / diagnosis catalogue
Pattern fitting, overlap, missing branch, unjustified coefficients, missing base state and algebra-before-model.

# G. First-move cues
Define what `T_n` counts in words; then ask whether every object enters exactly one structural branch.

# H. Support fading
Fade from supplied state plus branches to independent derivation. No recurrence formula is supplied on first mastery attempt.
