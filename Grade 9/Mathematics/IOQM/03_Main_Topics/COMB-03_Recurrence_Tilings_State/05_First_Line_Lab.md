# First-Line Lab

Write only the first structural line or state definition. The target is the model, not the final arithmetic.

1. A `2 x n` rectangle is tiled by dominoes. Define the counting state before writing any recurrence.

2. Count binary strings of length `n` with no consecutive 1s. Give an exactly-once first-symbol split.

3. Count compositions of `n` using 1 and 2 with no consecutive 2s. State the extra memory a recurrence needs.

4. Starting from 1, a machine allows `x -> x+1` or `x -> 2x`. The target is 100. Write the reverse predecessor rule before searching.

5. A number is represented using powers of 2, each usable at most twice. State a local representation suitable for left-to-right or low-to-high counting.

6. Count partitions of 8 into distinct parts. Give a compact include/exclude state or a direct representation; do not force a one-variable recurrence.

7. Count length-`n` words over `{A,B,C}` with adjacent letters different. State the symmetry that collapses the transition count.

8. A story describes repeated legal moves and asks whether a target can be reached. Write the question that decides whether this belongs to deterministic state evolution or adversarial-game strategy.
