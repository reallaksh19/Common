# NT-02 - Recognition and First-Line Lab

Write only the first useful line unless asked for a value.

1. Show `38 congruent 3 (mod 5)` using divisibility.
2. Decide whether `17=5` and whether `17 congruent 5 (mod 12)`.
3. Reduce `12345` modulo 7 before any further work.
4. Write the first four residues of `2^n mod 7`.
5. Last digit of `3^100`: state the modulus first.
6. Last two digits of `7^50`: state the modulus first.
7. From `3x congruent 6 (mod 7)`, write the inverse step.
8. From `2x congruent 4 (mod 6)`, state why direct cancellation modulo 6 is unsafe.
9. Solve-first-line: `x congruent 2 (mod 3)`, `x congruent 1 (mod 4)`.
10. Compatibility check: `x congruent 1 (mod 4)`, `x congruent 2 (mod 6)`.
11. Distinct residues of A and B modulo m: write the collision condition to avoid.
12. For `n^n mod 7`, name the two periodic pieces that must both be preserved.
13. Explain `a congruent b (mod m)` in one sentence without congruence notation.
14. Find an inverse candidate for 5 modulo 12.
15. State whether 6 has an inverse modulo 15 and why.
16. If `a congruent b (mod 9)`, write one valid statement involving `a^2,b^2`.
