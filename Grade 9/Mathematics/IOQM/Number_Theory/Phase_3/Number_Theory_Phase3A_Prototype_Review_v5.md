## Purpose

Validate the student-facing information design against the supplied Algebra reference before scaling Phase 3 to all 90 Appendix A + 20 Appendix B questions.

`Navigator -> rich reference core -> student support map -> Appendix A sample`

The expanded Advanced Bridges, full Appendix A/B/C, and reviewer dossier remain subsequent Phase 3 work.

   - first-move-only H3 Start where needed;
   - structural visuals only where they reduce cognitive load.

## Layout grammar accepted for scale-up

Every rich core skill page should reuse the following visual hierarchy:

- `What you probably remember` - cool neutral panel;
- `The missing IOQM link` - teal panel;
- mechanism/equations in open white space;
- `Worked bridge` - dark teal title bar;
- `First useful line` - green strip;
- `Close contrast` - violet strip;
- `Common mistake / legality` - amber strip;
- `Supports Appendix A` - quiet footer cross-reference.

This is richer through semantic chunking, worked mathematics, diagrams and whitespace rather than decorative imagery.

## Appendix grammar accepted for scale-up

Question header:

`NT-Qxxx · title    [CORE|BRIDGE|CHALLENGE] [BROAD FAMILY]`

Hints:

- H1 = one question-specific recognition sentence;
- H2 = one stable prior skill/bridge retrieval link;
- H3 = only the first executable setup/equation;
- easy questions may stop at H1;
- medium questions may stop at H2;
- difficult/mixed questions may use H3.

Normally 2--3 questions per page; hard/long questions may use more space.
