# Circle & Tangent Recognition — NMTC Bhaskara Preliminary P0

## Why this unit exists

Preliminary geometry is usually lost before calculation: the learner fails to mark the forced facts that make the diagram collapse.

This package uses the performance spine:

`SEE FIGURE -> MARK GIVEN -> MARK FORCED FACTS -> CHOOSE ONE RELATION -> CHAIN -> CHECK`

For circle/tangent problems, the first useful marks are often:

- radius perpendicular to tangent;
- equal tangents from one external point;
- equal radii / isosceles triangles;
- angle at centre vs angle at circumference;
- same-segment equal angles;
- diameter -> right angle;
- cyclic opposite angles supplementary;
- tangent-chord / alternate-segment transfer;
- intersecting-chord / secant power products;
- parallel-line angle transfer before applying a circle theorem.

## Student mastery target

The learner can:

1. identify the correct circle theorem from a sparse diagram;
2. mark forced right angles and equal lengths before chasing angles;
3. distinguish centre-angle, same-segment and cyclic-quadrilateral triggers;
4. use equal tangents and tangent-radius facts without re-proving them each time;
5. use alternate-segment reasoning with correct angle correspondence;
6. use intersecting-chord / secant power as a metric relation;
7. combine tangent facts with parallels, similarity and Pythagoras;
8. avoid assuming a diagram is to scale;
9. reject a geometry PYQ anchor when exact figure custody is missing or labels conflict.

## Cognitive contract

Concept learning:

`SEE -> REALIZE -> UNDERSTAND -> ADOPT`

Preliminary performance layer:

`RECOGNIZE -> MARK -> FIRST RELATION -> SHORT CHAIN -> CHECK -> TRANSFER`
