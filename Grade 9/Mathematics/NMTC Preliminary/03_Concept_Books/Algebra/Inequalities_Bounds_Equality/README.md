# Inequalities, Bounds & Equality Conditions — NMTC Bhaskara Preliminary P0

## Why this unit exists

The qualified Preliminary corpus does not support teaching inequalities as a bag of formulas.

The recurring decision sequence is:

`BOUND? -> DOMAIN? -> CHOOSE TOOL -> EQUALITY CONDITION -> VERIFY -> TRANSFER`

A solver must first decide whether the requested maximum/minimum even exists.

## Student mastery target

The learner can:

1. distinguish an inequality statement from an optimization problem;
2. test boundedness before trying AM-GM/Cauchy/completing squares;
3. identify the domain and sign restrictions that make an inequality legal;
4. derive and use AM-GM equality conditions;
5. use Cauchy/Engel form when reciprocal terms suggest it;
6. complete squares to prove lower/upper bounds;
7. use discriminant/root-existence reasoning as a bound tool;
8. solve absolute/rational inequalities through intervals and excluded points;
9. count integer/natural solutions only after the real interval is correct;
10. reject a supplied maximum/minimum claim when the expression is unbounded.

## Cognitive contract

Concept learning:

`SEE -> REALIZE -> UNDERSTAND -> ADOPT`

Performance layer:

`RECOGNIZE -> BOUNDEDNESS -> FIRST MOVE -> EQUALITY/DOMAIN -> SOLVE -> CHECK -> TRANSFER`
