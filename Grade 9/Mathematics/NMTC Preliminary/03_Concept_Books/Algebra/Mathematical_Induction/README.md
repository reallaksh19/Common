# Mathematical Induction — NMTC Bhaskara Preliminary

## Why this unit exists

Mathematical Induction is an explicit syllabus obligation even though the currently qualified 2018/2019/2023/2024/2025 Preliminary corpus does not provide a dense clean induction recurrence signal.

This package is therefore **syllabus-first**, not PYQ-frequency-first.

Performance spine:

`STATE P(n) -> CHECK TRUE START -> ASSUME P(k) -> BUILD P(k+1) FROM P(k) -> CLOSE CHAIN -> CHECK DOMAIN -> TRANSFER`

## Student mastery target

The learner can:

1. distinguish checking examples from proving all cases;
2. state `P(n)` precisely;
3. identify the correct first index;
4. write a valid base case;
5. use the induction hypothesis only in the allowed form;
6. transform the `k+1` case until the hypothesis becomes useful;
7. prove identities, divisibility statements and inequalities by induction;
8. decide when ordinary induction is awkward and strong induction is the better bridge;
9. detect broken induction proofs, false base cases and circular reasoning;
10. separate source-grounded evidence from author-created syllabus material.
