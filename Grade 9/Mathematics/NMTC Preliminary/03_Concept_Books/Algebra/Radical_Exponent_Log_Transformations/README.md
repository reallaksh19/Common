# Radicals, Exponents & Logarithmic Transformations — NMTC Bhaskara Preliminary P0

## Why this unit exists

The qualified Preliminary corpus repeatedly uses radicals, powers and logarithms as **representations to simplify**, not as isolated formula-recall chapters.

The recurring behavior is:

`SEE FORM -> FIND COMMON LANGUAGE -> TRANSFORM -> SOLVE SMALLER ALGEBRA -> CHECK DOMAIN -> TRANSFER`

Typical first moves include:

- rewrite radicals on a common basis;
- reconstruct conjugate surds as squares/cubes;
- normalize exponential bases;
- set a logarithmic expression equal to a simpler variable;
- convert log equations back to algebra;
- rationalize or replace a radical ratio by a symmetric invariant;
- check real/log/domain restrictions before accepting solutions.

## Student mastery target

The learner can:

1. simplify mixed square/cube/nth roots through a common radical basis;
2. recognize when `A±B√d` is a disguised square;
3. use conjugates and identities before expanding large powers;
4. normalize related exponential bases and introduce one useful variable;
5. understand logarithms as exponents, not merely memorize log laws;
6. choose `t=log_b x` or `t=sqrt(log_b x)` when structurally justified;
7. convert between logarithmic and algebraic forms with correct domain checks;
8. solve radical equations while distinguishing reversible and non-reversible operations;
9. use reciprocal/symmetric radical variables such as `x+1/x` where helpful;
10. identify source/key or notation conflicts instead of forcing a supplied answer.
