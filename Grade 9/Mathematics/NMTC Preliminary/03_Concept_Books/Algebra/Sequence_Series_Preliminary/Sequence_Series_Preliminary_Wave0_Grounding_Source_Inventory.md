# 6. Benchmark-parity gaps in the legacy architecture

Issue #49 is a **partial-knowledge assimilation rebuild**, not merely a repackaging of the existing speed overlay.

## GAP-01 — no mandatory partial-knowledge concept map

The existing package has route/spec/cards, but no single connected map explicitly linking:

`PRIOR -> HALF-KNOWLEDGE -> MISSING BRIDGE -> INVARIANT -> REPRESENTATION -> DECISION BOUNDARY -> FIRST MOVE -> TRANSFER -> SOURCE`.

Wave 0 closes this with:

`Sequence_Series_Preliminary_Assimilation_Concept_Map_v2.md`.

## GAP-02 — no integrated assimilation-book layer

The old overlay deliberately points learners back to the deep chapter. That is correct authority separation, but Issue #49 additionally requires one partial-knowledge **integration layer** that repairs the missing bridges across the six deep lenses under one Preliminary decision architecture.

Wave 2 must therefore teach the missing links without reauthoring the entire deep textbook.

## GAP-03 — formula/procedure ownership is not explicitly diagnosed

The old prerequisite route asks useful questions, but the new unit must distinguish:

- prerequisite missing;
- formula remembered without meaning;
- wrong mathematical object (`a_n` vs `S_n`);
- representation/recognition failure;
- endpoint/index/convergence error;
- execution error;
- source-integrity error.

## GAP-04 — close contrast pairs are present but not yet the organizing spine

Issue #49 requires explicit near-boundaries such as:

- `a_n` vs `S_n`;
- AP vs GP;
- finite vs infinite GP;
- direct term formula vs reverse from `S_n`;
- high-index expansion vs cancellation;
- recurrence discovery vs closed-form verification;
- ordinary summation vs telescoping;
- primary sequence mechanism vs incidental sequence appearance.

## GAP-05 — H3->H0 fading is not yet operational across the integrated package

The legacy assets contain hints/ladders, but Wave 2 must show actual progressive removal of support after an attempt, not merely provide card-level first moves.

## GAP-06 — answer leakage in legacy transfer-bank form

The current transfer bank places each answer/solution directly below its item. It is valid as an internal reviewed bank, but it cannot serve unchanged as the final student attempt surface.

Wave 4 must separate:

- student paper;
- teacher answer/diagnostic authority.

## GAP-07 — recurrence transformation needs a stronger decision boundary

Reciprocal and shift cards already exist, but the rebuilt package must make the learner decide **which transform fits the algebraic shape** rather than treating reciprocal/shift as isolated tricks.

## GAP-08 — telescoping requires explicit endpoint custody

The old package correctly teaches rational/radical telescoping. The assimilation rebuild must diagnose the common error where cancellation is recognized but the first/last survivor is lost.

## GAP-09 — finite differences need degree-hypothesis discipline

A constant second difference is a structural signal, not permission to accept an unverified guessed nth term.

## GAP-10 — production/render QA is still NOT_RUN

Current legacy QA explicitly lists final notation/typography/render QA as not run. Wave 5 must render and inspect every final page.
