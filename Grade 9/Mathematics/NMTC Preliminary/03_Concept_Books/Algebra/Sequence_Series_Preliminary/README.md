# Sequence & Series — NMTC Bhaskara Preliminary Overlay

## Purpose

This package is an **NMTC Preliminary performance overlay** on the existing deep chapter:

`Grade 9/Mathematics/Sequence and Series/`

It does **not** duplicate the existing AP/GP/sigma derivations. The deep chapter remains concept authority; this overlay adds Previous-Year grounding, first-move recognition, speed practice, source QC and mixed Preliminary transfer.

## Upstream concept authority

Use the existing chapter for:

- POSITION — term/index/nth term/recurrence;
- CHANGE — finite differences and AP;
- RATIO — GP and selected terms;
- ACCUMULATION — series, `S_n`, sigma and power sums;
- TRANSFORM — reciprocal/telescoping/odd-even/factor transforms;
- REVERSE — `a_n=S_n-S_{n-1}`.

Concept method remains:

`SEE -> REALIZE -> UNDERSTAND -> ADOPT`

## Preliminary performance spine

`RECOGNIZE -> WRITE THE RIGHT OBJECT -> TRANSFORM -> COLLAPSE -> CHECK -> TRANSFER`

A student should decide rapidly whether the problem is about:

- a term or a sum;
- additive change or multiplicative ratio;
- standard accumulation or a weighted/nested sum;
- a recurrence that should be transformed;
- a high-index GP where powers cancel;
- an infinite GP where `|r|<1` must be checked;
- cumulative information that should be reversed.
