# Counting, Permutations, Pigeonhole & Inclusion–Exclusion — NMTC Bhaskara Preliminary

## Why this unit exists

The qualified Preliminary corpus shows that combinatorics is rarely just “choose a formula.” The recurring behavior is:

`DEFINE THE OBJECT -> IDENTIFY RESTRICTIONS -> CHOOSE REPRESENTATION -> COUNT DISJOINTLY -> CHECK OVERLAP -> TRANSFER`

The package connects fundamental counting, permutations/combinations, digit restrictions, subset products, coefficient counting, state/path counting, pigeonhole and inclusion–exclusion.

## Student mastery target

The learner can:

1. distinguish ordered arrangements from unordered selections;
2. use multiplication/addition principles before reaching for `nPr`/`nCr`;
3. count under repetition, position, parity and divisibility restrictions;
4. split a count into disjoint exhaustive cases;
5. interpret a coefficient as the number of combinatorial choices;
6. convert a sum over subsets into a product expansion when appropriate;
7. define states for constrained path/counting problems;
8. apply pigeonhole by identifying pigeons, boxes and forced occupancy;
9. use inclusion–exclusion to correct double-counting;
10. recognize when a historical counting PYQ is figure/source-gated and cannot be reconstructed safely.

## Cognitive contract

Concept learning:

`SEE -> REALIZE -> UNDERSTAND -> ADOPT`

Preliminary performance layer:

`RECOGNIZE -> DEFINE OBJECT -> FIRST COUNT -> CORRECT OVERLAP -> CHECK -> TRANSFER`
