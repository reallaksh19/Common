# NMTC Bhaskara Preliminary — Grade IX & X Mathematics

## Scope

This workspace is **Preliminary / Screening Test only** for the NMTC Junior (Bhaskara) level, Grades IX–X.

`SEE -> RECOGNIZE -> FIRST MOVE -> SOLVE EFFICIENTLY -> CHECK -> TRANSFER`

`SEE -> REALIZE -> UNDERSTAND -> ADOPT`
