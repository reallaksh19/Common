## Retest protocol

For every high-value miss:

1. identify the exact error code;
2. review the corresponding First-Step card;
3. solve one lower-level ladder item only if the first move itself is unstable;
4. solve one non-identical transfer item;
5. wait until the next mixed session;
6. retest without chapter labels.

A student should not immediately redo the same mock question from memory and call that transfer.
