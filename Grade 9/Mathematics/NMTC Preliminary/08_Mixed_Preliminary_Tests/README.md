# NMTC Bhaskara Preliminary — Mixed Assessment System

This directory contains two assessment layers:

1. **package mastery tests** — unlabelled tests within one major concept package;
2. **full mixed mocks** — cross-package Preliminary simulations where the student must identify the domain and first move independently.

## T24 training profile

The v1 full mocks use a current-like author-created format grounded to the qualified 2024 paper:

- 30 questions;
- 120 minutes;
- first 15 multiple choice;
- next 15 numerical response;
- training score `+1/-0.5/0`.

This is **not** claimed as the universal historical NMTC format.

## How to use the three mocks

### Before Mock A

Student should have completed package-level mastery tests and mixed First-Line work.

### After each mock

Do not immediately redo the same questions.

Use:

`miss -> error code -> First-Step card -> smallest needed ladder repair -> non-identical transfer -> later mixed retest`

### Progress signal

Track separately:

- raw training score;
- correct/wrong/blank;
- first-move recognition accuracy;
- error-code distribution;
- package clusters;
- completion time;
- questions correct only after excessive search.

No psychometric pass threshold is frozen before classroom calibration.
