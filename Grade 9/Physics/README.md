# Grade 9 Physics

This folder contains subject-level Physics learning products and chapter workspaces that are grounded to source material and produced through the reusable Grade 9 skill family.

## Teaching architecture

For concept/reference books, use:

`SEE THE EQUATION -> REALIZE -> UNDERSTAND`

with `CONNECT` used for source traceability and navigation.

The reusable methodology lives in:

`Grade 9/skills/grade9-physics/references/concept-book-see-realize-understand.md`

The Physics skill authority lives in:

`Grade 9/skills/grade9-physics/SKILL.md`

## Product separation

- **Concept Book** — Why does this physics work?
- **First-Step Reference Book** — How do I start this problem?
- **Question Bank** — Can I solve and transfer independently?

Do not collapse these into one undifferentiated formula/practice book.

## Current chapter workspaces

- `Motion/` — Motion in a Straight Line; grounded to the 68-question supplied source bank.

## Source-grounding rule

Each chapter workspace should preserve:

- source authority/provenance;
- concept IDs;
- Source -> Concept coverage map;
- source QA flags;
- human-readable specification;
- machine-readable mapping where useful;
- generated artifacts or an artifact manifest.
