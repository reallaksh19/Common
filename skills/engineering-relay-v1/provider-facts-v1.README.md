`reconcileGitHubFacts(scope,options)` uses a new native GET for exactly specified current GitHub issue, up to 3 children, up to 4 PRs, and GitHub Actions run list for each **provider-returned current PR head SHA**. Its `scope` has exactly `repository`, `parent_issue`, `child_issues`, `pull_requests:[{number,expected_head_sha}]` and `workflow_paths` (fixed literal workflow paths, not titles). The caller-specified parent-child association is *unverified*, not an authentication or a real root-trace guarantee. It validates native issue IDs/links and PR head/base repository, state, draft, merged and creation/update times. **Never interprets agent-authored issue titles/PR prose as accepted engineering status.** It rejects redirects, unexpected response URLs, foreign PR repos, oversized JSON and unbounded scopes.

Its currentness state is `MATCH`/`STALE`/`UNPINNED` against independent expected head; CI workflow facts are `PASS`/`FAIL`/`PENDING`/`UNKNOWN` only at the actual provider-returned head, checked against exact workflow **path**. Missing exact-head run is UNKNOWN (not zero fails/pass), queued/in progress PENDING, failure/cancelled FAIL. If GitHub reports more than 100 Actions runs, it refuses to claim absence based on incomplete pagination and reports UNKNOWN. `PASS` indicates exact-head hosted CI only, NOT independent review, Owner authorization, independently accepted TASK_EVIDENCE or programme AC credit. This is a source facts read model, not actual-next **decision authority**.

Returns one bounded `relay-provider-facts-v1` snapshot with a canonical SHA256, `observed_at`, full original GitHub immutable observation refs, source truth labels, parent/child/PR facts and statuses. It does **not** include raw issue or PR bodies, private transcripts, tokens or automatic issue/PR writes. Native source status `PROVIDER_OBSERVED` vs injected test status `INJECTED_UNVERIFIED` is explicit. Digest is deterministic **for the same facts and observed_at**, not across different polling intervals. Unknown review/Owner source remains NOT_EVALUATED/NOT_AUTHENTICATED, and all acceptance/writer flags false.
