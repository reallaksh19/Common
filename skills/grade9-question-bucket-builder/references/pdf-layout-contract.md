# Grade 9 Question Bucket PDF Layout Contract

## Page types

Use these page types in order unless the user requests otherwise.

1. **Cover page**
   - Group number and bucket title.
   - Hidden invariant sentence.
   - Source status: uploaded/source/adapted/external cited.

2. **Source trace page**
   - Table of source questions, pages, roles, and citation status.
   - Note any OCR/notation cleanup.

3. **Core concept page**
   - Concept card.
   - Formula/tool card.
   - First-move recognition card.
   - Misconception card.

4. **Anchor solution page**
   - Question.
   - Concept -> Application -> Solution -> Check.
   - Avoid more than 6-8 algebra lines per visual block.

5. **Extension page(s)**
   - Question variants from the same source group.
   - What changes / what stays invariant.
   - Compact worked steps.

6. **Transfer page**
   - CBSE/NCERT-aligned variation.
   - IOQM verified or IOQM-style adapted variation.
   - IMO-foundation transfer.
   - Clear label for each.

7. **Exit ticket page**
   - First-move prompts.
   - Short answer key.

8. **References page**
   - Uploaded source references.
   - Repository methodology references.
   - External official citations.

## Design rules

- Use A4 portrait unless geometry diagrams need wider layout.
- Use clear margins and readable font sizes.
- Use short paragraphs and card blocks.
- Use source tags such as `[SOURCE Q2(ii)]` beside question headings.
- Use callouts for hidden invariant and first useful line.
- Put long answer keys after question pages.
- Keep source and generated questions visually separate.

## Math rendering rules

- Prefer Unicode math for simple Grade 9 expressions: `√`, `∛`, `²`, `³`.
- Use equation blocks for multi-step algebra.
- Keep fractions readable; use stacked fractions only if the PDF engine supports them well.
- Avoid raw LaTeX in student-facing PDF unless it renders correctly.

## Inspection checklist

Before delivery, render the PDF pages and check:

- no clipped equations;
- no blank pages;
- diagrams are visible and labelled;
- source citations are readable;
- generated questions are not confused with source questions;
- answer key appears after questions;
- page count is reported in the final response.
