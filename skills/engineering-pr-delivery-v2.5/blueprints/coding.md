# Coding blueprint

For each material batch: reconfirm active EP/scope; make the smallest coherent change advancing named ACs; keep state ownership explicit; avoid duplicated business rules and hidden fallback authority; preserve compatibility unless authorized; fail clearly only at true authority/safety boundaries; remove in-scope dead paths; run narrow checks during iteration and required checks before completion; persist discoveries/evidence truth.

Tests passing does not by itself prove maintainability or code quality.
