# GitHub delivery blueprint

GitHub projects roadmap/work custody; it does not replace it. Link issues to roadmap nodes, maintain parent/dependency/supersession relationships, expose current EP/checkpoint pointers, close only after roadmap/acceptance/evidence/PR/remaining-work reconciliation, and transfer unresolved obligations on supersession. Do not use an issue comment as the only durable source of Owner intent or execution context.

Merge authority remains separate from mergeability and stays Owner-controlled unless explicitly granted.
