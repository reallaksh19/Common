# Code review blueprint

Review against roadmap intent and EP scope, acceptance, state/authority ownership, regressions/compatibility, error/stop semantics, coupling/cohesion/duplication, test adequacy/independent evidence, user-facing clarity, stale/dead behavior, and applicable performance/accessibility.

Classify findings as `REQUIRED_FOR_ACCEPTANCE`, `QUALITY_FINDING`, `FOLLOW_UP`, or `OWNER_DECISION_REQUIRED`. Do not call every finding a blocker.
