# Grade 4 English V2 Publication

Canonical learner/adult publication consumes `LearningRepresentationPlan` from the English V2 authoring handoff.

Publication may:

- arrange and style validated prompts, response structures, source models, representations, hints, retries, rubric criteria, and misconception watches;
- choose page geometry, typography, colours, spacing, and purely decorative visual treatment.

Publication may **not** invent:

- grammar categories or source rules;
- hints, misconceptions, diagnostic claims, or fresh-retry semantics;
- model-answer truth for interpretive/open responses;
- learner traits or mastery claims;
- new assessment requirements not present upstream.

Canonical outputs:

1. student study guide;
2. student practice workbook;
3. teacher/parent diagnostic key.

All three are generated from the same authoring handoff so source coverage and pedagogical intent cannot drift between artifacts.
